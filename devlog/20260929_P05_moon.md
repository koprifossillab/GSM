# 달 — 지구 밖 첫 지역 (계획)

2026-09-29 · sclee · 사람이 물었다: "달을 구현할 수 있을까? 한번 계획 문서 짜줘."
**된다.** 아래는 오늘 상류를 한 장씩 쏴 보고 적은 것이다. 짓는 것은 사람이 차례를 정한 뒤다.

## 0. 한 줄

USGS 의 **달 통합 지질도 1:500만**(2020)을 파일로 받아 우리가 그리고(GeoMAP 의 길, 018),
LRO·가구야 영상과 LOLA 표고 음영을 **브라우저가 곧장** 배경으로 부른다(EOX 의 길). 문(`requests`)은
늘지 않는다. 가장 큰 일은 자료가 아니라 **"GSM 은 지구 위에 있다" 는 가정을 코드에서 걷어내는 것**이다.

## 1. 무엇을 얹나 — 쏴 본 것

### 지질 — USGS Unified Geologic Map of the Moon, 1:5M, 2020

| | |
|---|---|
| 만든 이 | Fortezzo (USGS)·Spudis (LPI)·Harrel (SD Mines). USGS Astrogeology 가 펴냈다 |
| 받는 곳 | `asc-astropedia.s3.us-west-2.amazonaws.com/Moon/Geology/Unified_Geologic_Map_of_the_Moon_GIS_v2.zip` (214 MB, 2024-07-09) |
| 든 것 | FileGDB 와 **셰이프파일 둘 다.** `GeoUnits`(면 **12 247**, 126 MB)·`GeoContacts`(경계선 66 MB)·`Linear_Features`(능선·열곡 4 MB)·`Labels_Global` |
| 투영 | `Moon2000_EquidistantCylindrical_clon0` — 반지름 **1 737 400 m** 구, 등거리 원통, 미터 |
| 색 | **`GeologyUnit_colors.csv` 가 딸려 온다** — 단위 기호 → hex. 우리가 색을 따지 않아도 된다 |
| 뜻 | `..._DOMU_descriptions.csv` — 단위마다 Name·Description·Interpretation (영어) |
| 조건 | USGS 저작물이라 공개 영역으로 본다. **다운로드 페이지에서 조건 글을 아직 못 봤다** — 지을 때 메타데이터(`.shp.xml`)의 `useconst` 를 읽고 여기를 닫는다 |

geo3al(025)과 닮았다 — 셰이프파일을 `struct` 로 읽고 투영이 단순하다. 다른 것은 **면이 1만 2 천에
126 MB** 라는 것이다. 모양 한 덩이(GeoJSON)로 줄 수 없다(geo3al 은 5 천 면 남짓). 그래서 **서버가
타일을 굽는다** — GeoMAP(018, 9 만 9 천 면)의 길이다. 한 번 `manage.py build_moon` 이 셰이프파일을
sqlite 한 장(R*Tree 딸림)으로 옮기고, 그 뒤로는 `geomap.py` 가 하는 일을 한다. GDAL 은 쓰지 않는다.

### 배경 — USGS 달 WMS, NASA Moon Trek

| 곳 | 무엇 | 확인 (2026-09-29) |
|---|---|---|
| `planetarymaps.usgs.gov/cgi-bin/mapserv?map=/maps/earth/moon_simp_cyl.map` | `LROC_WAC`(영상)·`LOLA_Kaguya_Shade`(음영)·`LOLA_color`(표고 색)·`KaguyaTC_Ortho`·`Moon1M_Quads`(도폭 경계) 등 12 | `GetMap` 200, `EPSG:4326` 으로 준다. **CORS `*`**. 키 없다 |
| 같은 서버 `moon_npole.map`·`moon_spole.map` | 극 평사도법 `LRO_WAC_*`·`LOLA_*` | 200. **함정** 아래 |
| `trek.nasa.gov/tiles/Moon/EQ/<레이어>/1.0.0/default/default028mm/{z}/{y}/{x}.jpg` | WMTS, 경위도 격자 | 200, **CORS `*`** |

- **함정 — 극지 WMS 는 제 IAU 코드로 물으면 빈 그림을 준다.** `SRS=IAU_2015:30120` 은 667 바이트
  흰 판이고, 같은 범위를 **`SRS=EPSG:32761`** 로 물어야 그림이 온다. 32761 은 지구의 UPS 남극 코드인데
  여기서는 이름만 빌려 **달 반지름·가짜 동거(false easting) 0** 인 달 극 평사도법을 뜻한다 — 범위가
  `±931 100 m` 로 가운데가 0 이다. 지구의 32761(가짜 동거 2 000 km)로 여기면 엉뚱한 곳을 묻는다
- 둘 다 키가 없고 CORS 가 열려 있어 **브라우저가 곧장 부른다**(EOX·GIBS 와 같다). 문을 내지 않는다.
  캐시·미리 데우기가 필요해지면 그때 `usgsastro.py` 를 문으로 세운다 — 지금은 아니다
- 출처 표기 — LROC WAC 는 NASA/GSFC/Arizona State University, LOLA 는 NASA/GSFC, 가구야(SELENE)는 JAXA

## 2. 지구라고 믿고 있는 자리 — 먼저 걷어낼 것

오늘 코드를 훑어 찾은 것이다. **이것들이 달 탭에서 틀린 답을 낸다** — 대부분 소리 없이.

| 자리 | 지금 | 달에서 |
|---|---|---|
| 거리·넓이 (`map.js` 의 `ol.sphere.getLength`·`getArea`·`getDistance`, 1640·1737·1753 줄 둘레) | 지구 반지름 기본값 | `radius: 1737400` 을 넘긴다. 지역 명세에 `radius` 를 둔다 |
| 축척 막대 | 투영의 `metersPerUnit` | 달 투영을 옳게 정의하면 저절로 맞다 (§3) |
| `toLL`/`fromLL` | `ol.proj.toLonLat` — 지구 경위도 | 달 경위도가 나와야 한다. §3 의 투영이면 숫자는 그대로다 |
| 좌표계 고르개(TM·UTM-K·Bessel, 013) | 한국·동아시아에서만 뜬다 | 이미 가려진다. 달 탭에서도 끈다 |
| VWorld·주소 찾기·지명 | `spec.vworld` | 끈다. 찾기 칸은 **좌표와 달 지명**(§6) |
| 점묶음 | 지구 것 하나뿐이다 | **몸(`body`)을 갖는다** — §5 |
| 시료 고도(`fill_elevation`, 031) | AWS·국토지리원·PGC | 달 점묶음에서는 LOLA 로 가거나 끈다 |
| 3D 단추 | 지구 지형 | 4 단계까지 숨긴다 |
| 그림 내려받기의 띠 | "위도·경도" | "달 위도·경도" 와 출처 |
| 지질시대 옮기기(`i18n`) | ICS 표 | 달의 시대는 ICS 밖이다 — §4 |
| `prewarm`·`upstream_stats` | 지구의 상류 | 브라우저가 곧장 부르므로 해당 없다 |

## 3. 화면 — "달" 탭, 경위도 그대로

**지역 탭 하나를 더한다 — `moon`.** 지역마다 투영이 다른 틀(017)이 이미 있다.

- **투영: 달 경위도를 도(°) 단위 평면으로.** `ol.proj.Projection({code: "IAU_2015:30100", units: "degrees",
  extent: [-180,-90,180,90], metersPerUnit: 2π·1737400/360 ≈ 30 323.6})`. 이러면
  - USGS WMS 를 `EPSG:4326` 이라 적고 **같은 숫자**로 물을 수 있다 — 옮겨 그리기가 없다
  - Moon Trek 의 경위도 격자(`default028mm`)도 그대로 맞는다
  - 축척 막대가 달의 미터를 읽는다
  - 지질도 셰이프파일(미터)은 굽는 단계에서 `x / R` 로 도로 바꾼다
- 지구의 `EPSG:4326` 을 그냥 쓰지 **않는다** — OpenLayers·proj4 가 지구 타원체로 여겨 거리·축척이
  3.67 배 틀어진다. 코드를 따로 두는 것은 "이 숫자는 달의 경위도다" 를 코드가 알게 하려는 것이다
- **남극은 따로 둔다 — "달 남극" 탭.** 아르테미스 착륙 후보가 남위 84–90° 에 몰려 있는데,
  경위도 평면에서는 거기가 띠로 늘어난다. 지구의 남극 탭(3031, 017)처럼 극 평사도법으로 본다.
  배경은 `moon_spole.map`(**`EPSG:32761` 이라 적고 묻는다**, §1). 지질도 타일 격자는 GeoMAP 의
  3031 격자 코드를 **반지름을 매개변수로 받게** 넓혀 쓴다(`geomap.py` 는 지금 WGS84 타원체에 묶여 있다)
- 달 탭은 **묶음이 아니다.** 북극·동아시아 묶음 탭에 끼지 않는다 — 몸이 다르다
- 테마 — 지역마다 색이 있다(016). 달은 **월광 은회색에 먹빛**, 딴 빛을 하나 둔다면 LOLA 표고 색의 청록

## 4. 지질도 — 단위·시대·속성

- **레이어** — 레이어군 "달 지질 (USGS)" 아래 셋: `moon:units`(면, 타일로 굽는다)·`moon:contacts`
  (경계선)·`moon:linear`(능선·열곡·단층). 면과 선을 한 장에 구울지 따로 굽을지는 GeoMAP 처럼
  따로 둔다 — 켜고 끄는 일이 잦다
- **색** — `GeologyUnit_colors.csv` 를 `data/moon_styles.json` 으로 옮겨 그리는 것과 범례가 같은 표를
  읽는다(022). 올린 색을 바꾸면 `RENDERER` 를 올린다(018 의 규약)
- **속성** — 클릭한 점이 드는 면을 R*Tree 로 찾고 `Unit`·`Name`·`Description`·`Interpretation` 을 낸다.
  **값은 옮기지 않는다**(CLAUDE.md "영어판") — 영어 그대로 뜬다. 열 이름만 `PROP_EN`·한국어 이름을 단다
- **달의 지질시대는 옮긴다** — 규칙이 "지질시대 값만은 옮긴다" 이다. 단위 기호의 머리가 시대다:
  `C` 코페르니쿠스기 · `E` 에라토스테네스기 · `I`(`Il`·`Ie`) 임브리움기(후기·전기) · `N` 넥타리스기 ·
  `pN` 선넥타리스기. **한국어 표기는 정해야 한다** — ICS 한글판에는 없다. 한국 천문·행성 학계의
  쓰임을 사람이 확인한다(§8)
- **파일 자리** — `GSM_MOON_DIR`, 기본 `<DB 옆>/moon/`, 운영 `/srv/GSM/db/moon/`. 원본은
  NAS `N:\GSM\sources\moon\`. **저장소에 두지 않는다.** 없으면 안내가 뜨고 배경은 그대로 돈다

## 5. 점묶음 — 몸을 가른다

아폴로·루나 시료 채취 지점, 창어 착륙지를 올리고 싶어질 것이다. 지금 `PointSet` 은 지구 좌표라고
여긴다 — 달 좌표를 올리면 **지구 탭에 엉뚱하게 뜬다.**

- `PointSet.body` — `earth`(기본)·`moon`. 이주 하나. 올릴 때 달 탭에서 올리면 `moon`
- 지구 탭은 `earth` 만, 달 탭은 `moon` 만 그린다. 3D·그림 내려받기도 같다
- 시료 고도(`fill_elevation`)는 `moon` 이면 LOLA 로 가거나(4 단계와 함께), 그 전에는 단추를 숨긴다
- "점은 위경도 하나" 라는 뜻(CLAUDE.md "자료의 층")은 그대로다 — **어느 몸의** 위경도인지가 붙을 뿐이다

## 6. 찾기 칸 — 달 지명

IAU 행성 지명 사전(Gazetteer of Planetary Nomenclature)이 달의 크레이터·바다·산 이름과 가운데 좌표를
준다. 파일로 받아(`data/` 가 아니라 `<DB 옆>/moon/` — 크다면) 찾기 칸이 뒤진다. 스발바르의 NPI 지명
(`places`, 021)과 같은 자리다. **받는 주소와 꼴은 아직 안 쏴 봤다.**

## 7. 3D — 뒤로 미룬다

MapLibre 는 지구 메르카토르뿐이지만, 달 경위도를 지구 경위도라 속이고 얹으면 **구의 겉은 그대로
보인다.** 걸리는 것 둘.

- **높이의 축척** — MapLibre 는 지구 둘레로 미터를 잰다. 달 표고를 그대로 주면 산이 지구 비율로
  서서 **3.67 배 납작해 보인다.** Terrarium 으로 구울 때 표고에 `6378137 / 1737400` 을 곱해 둔다
  (눈으로 보는 비율만 맞춘다 — 팝업의 표고 숫자는 원래 값을 낸다)
- **남위 85° 안쪽이 없다** — 달 남극의 착륙 후보가 거기다. 3D 로 가장 보고 싶은 자리가 빠진다.
  그래서 3D 의 값이 지구보다 낮다
- 표고 원본은 LOLA+가구야 SLDEM2015(적도 ±60°, 약 60 m)와 LOLA 극지 DEM. 서버에 GDAL 이 없으니
  한반도 음영판(027)처럼 **작업 PC 에서 미리 잘라** `<DB 옆>/moon/dem/` 에 둔다

## 8. 정할 것 — 사람에게 묻는다

- **달의 시대 한국어 표기** — 코페르니쿠스기? 코페르니쿠스대? 선넥타리스기? 이름이 정해지면
  `i18n` 에 표로 둔다
- **달 남극 탭을 처음부터 둘까** — 둔다면 1 단계에 하루가 는다
- **다누리(KPLO)** — 감마선분광기(KGRS)를 한국지질자원연구원이 만들었다. 원소 분포도가 공개되면
  "지오빅데이터 뷰어가 KIGAM 의 달 자료를 얹는다" 는 이 저장소에 가장 어울리는 레이어다.
  **공개 여부·받는 곳은 아직 확인하지 않았다** — 한국항공우주연구원 쪽을 사람이 알아본다
- 이름 — 탭 "달" / "Moon". 대돌여지도에 달이 뜨는 셈이다
